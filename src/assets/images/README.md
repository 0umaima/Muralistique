# Images du site

Chaque fichier ici est un **espace réservé** généré par `scripts/generate-placeholders.mjs`.

**Pour mettre vos photos :** remplacez le fichier par le vôtre **en gardant exactement le même nom**.
Astro se charge du redimensionnement, des formats modernes (AVIF/WebP) et du chargement différé.
